# gdc-lakeflow-connector

Prototype home of the Geo Data Connector (GDC) community connector for
Databricks Lakeflow Connect. Connector source: [`sources/gdc/`](sources/gdc/).

Dogfood: Databricks Add Data UI -> Custom connector -> this repository URL,
source name `gdc`.

Destined for contribution to databrickslabs/lakeflow-community-connectors.

Setup runbook: [docs/pipeline-setup.md](docs/pipeline-setup.md)
